# Portrait Painting – Part 2 of 3
## September 14, 2026

# Main Studio Goal

Apply base colors that establish the **middle value** of the painting.

The midtone becomes the foundation for later:

- Darker shadows
- Lighter highlights
- Depth
- Three-dimensional form

Cover the **entire canvas**, including the background.

# Base Color Process

1. Select the color family for each area.
2. Mix a middle-value version of each color.
3. Use a relatively thin layer of paint.
4. Cover the portrait.
5. Cover the background.
6. Avoid leaving large white canvas areas.
7. Allow the base layer to dry.
8. Later build darker shadows and lighter highlights.

# Composition Principles

## Balance

Balance is the distribution of visual weight.

### Symmetrical Balance

Similar elements appear in corresponding positions on both sides.

### Asymmetrical Balance

Different objects or shapes create equal visual weight.

Balance can be created using:

- Color
- Value
- Shape
- Size
- Placement
- Direction

---

# Focal Point

A focal point is an emphasized area that attracts attention.

In a portrait, the face naturally tends to become the focal point.

A focal point can be strengthened through:

- Color
- Contrast
- Value
- Placement
- Shape
- Detail

A painting does not absolutely need one focal point, but it can be a useful compositional tool.

---

# Open Form and Closed Form

## Open Form

Some elements appear to continue beyond the edge of the canvas.

This allows the viewer's imagination to continue outside the frame.

## Closed Form

The objects remain completely inside the canvas.

The viewer's attention stays inside the picture.

For our current composition practice, open form is encouraged.

---

# Value

Value means:

**Light and dark**

Value helps create:

- Form
- Volume
- Space
- Depth

Greater value contrast can make an area appear closer.

Lower contrast can make an area recede.

# My Part 2 Goal

For my portrait, I should check:

- Is the entire canvas covered?
- Are my base colors mostly mid-values?
- Is the face a clear focal point?
- Is the composition balanced?
- Does the background support the portrait?
- Can I use open form effectively?
- Am I leaving room to add darker and lighter values later?
